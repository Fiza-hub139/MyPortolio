# 🚀 Interactive Developer Portfolio

A modern, responsive, and visually dynamic portfolio website featuring a **3D interactive terminal visual**, **synchronized typewriter animations**, and a **multi-theme system** supporting high-tech cyberpunk, quantum, and light/dark aesthetic tokens.

---

## ✨ Features

- **🎨 Multi-Theme System**: Dynamic CSS theme tokens allowing seamless real-time switching between 5 themes:
  - 🟢 `Cyber Lime`
  - 🩷 `Electric Dusk`
  - 🟦 `Liquid Quantum` *(Default)*
  - ⚪ `Monochrome`
  - ☀️ `Quantum Light`
- **💻 Dynamic Interactive Terminal**: Custom JavaScript component displaying developer skill stacks with terminal-style command typing without layout shift or unwanted scrollbars.
- **✨ Typing Title Animation**: Smooth, synchronized typewriter effect on the hero section for displaying roles seamlessly on a single line.
- **📱 Fully Responsive**: Custom CSS Grid and Flexbox structures optimized across all viewports (Mobile, Tablet, Desktop).
- **⚡ Performance & Smooth FX**: Built with vanilla Web technologies (HTML5, CSS3, JavaScript) for fast loading times, ambient glow gradients, and glassmorphism UI elements.

---

## 🛠️ Tech Stack

- **Markup & Structure**: HTML5
- **Styling & Theme Engine**: CSS3 (CSS Custom Properties, Glassmorphism, CSS Animations, Grid & Flexbox)
- **Dynamic Logic**: Vanilla JavaScript (ES6+, Async/Await Animations, Dynamic DOM Injection, LocalStorage Persistence)
- **Icons**: FontAwesome 6
